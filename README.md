# Insure On The Spot Page Recreation

Frontend recreation of the Insure On The Spot Blog, Locations, and Contact pages.

## What I tested

- Desktop, tablet, and mobile layouts.
- Responsive navigation and keyboard focus states.
- Blog, Locations, and Contact page navigation.
- Phone, quote, payment, renewal, directions, and location links.
- Location map loading and office open/closed indicators.
- Contact form required-field validation.
- Hero and CTA imagery at responsive breakpoints.
- No horizontal overflow on mobile.

## Improvements made

- Added responsive hero and Contact CTA imagery using the supplied transparent assets while keeping text and calls to action readable.
- Added page descriptions, canonical URLs, Open Graph metadata, and structured data to strengthen technical SEO.
- Added the supplied branded `assets/curve.svg` to the footer and preserved the original blue visual direction.
- Improved responsive layouts for office cards, contact content, navigation, and CTA sections.

## Contact form

The form is a frontend interaction preview. Required fields are validated locally, but no backend submission service was added because this trial task focuses on the frontend recreation.
